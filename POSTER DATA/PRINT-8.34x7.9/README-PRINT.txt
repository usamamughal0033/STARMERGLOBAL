------------------------------------------------------------
SEND THESE TO THE FLEX PRINTER  (use the PDFs - sharp vector text):
   - poster-left.pdf
   - poster-right.pdf

If the printer needs a raster file instead, use the PNGs:
   - poster-left.png    (9608 x 9101 px = ~96 DPI at full 100.08 x 94.8 in)
   - poster-right.png

------------------------------------------------------------
PRINT SETTINGS
   - Print at ACTUAL SIZE / 100% - 100.08 in x 94.8 in. Do NOT "fit/scale".
   - Background runs full-bleed to the edge. If the shop wants bleed, ask
     them to add 0.25 in mirrored bleed on all sides.
   - Files are RGB; let the print shop convert to CMYK on their RIP.

------------------------------------------------------------
TO RE-EXPORT YOURSELF (optional)
   Open poster-left.html / poster-right.html in Google Chrome ->
   Print (Ctrl+P) -> Destination: "Save as PDF" ->
   Paper size: custom 100.08 x 94.8 in -> Margins: None ->
   "Background graphics": ON -> Save.
   (Keep the "assets" folder next to the HTML files. Internet is needed
    once so the Inter font loads; it then embeds into the PDF.)
