STARMER — EXPO POSTERS (Print Pack)
===================================

SIZE: 3 ft x 7 ft  (36 in x 84 in), portrait.
Two posters designed as a matched LEFT + RIGHT pair for the showcase:
   • poster-left   = "Who We Are" (group, capabilities, custom parts)
   • poster-right  = "Trusted By Industry Leaders" (client wall)

-----------------------------------------------------------------
SEND THESE TO THE FLEX PRINTER  (use the PDFs — vector, infinitely sharp):
   • poster-left.pdf
   • poster-right.pdf

If the printer asks for a raster file instead, use the high-res PNGs:
   • poster-left.png    (5184 x 12096 px  ≈ 144 DPI at full 36x84")
   • poster-right.png

-----------------------------------------------------------------
PRINT SETTINGS
   • Print at ACTUAL SIZE / 100% — 36 in x 84 in. Do NOT "fit/scale".
   • Background runs full-bleed to the edge. If the shop wants bleed,
     ask them to add 0.25 in mirrored bleed on all sides.
   • Files are RGB; let the print shop convert to CMYK on their RIP.

-----------------------------------------------------------------
TO RE-EXPORT YOURSELF (optional)
   Open poster-left.html / poster-right.html in Google Chrome →
   Print (Ctrl+P) → Destination: "Save as PDF" →
   Paper size: custom 36 x 84 in → Margins: None →
   "Background graphics": ON → Save.

   (Keep the "assets" folder next to the HTML files — the logos and
    client images load from there. Internet is needed once so the
    Inter font loads; it is then embedded in the PDF.)
